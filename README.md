# ALCOM — სტატიკური საიტი

`https://alcom.ge`-ის სტატიკური ასლი, გამზადებული GitHub Pages-ისთვის.

## რა არის აქ

| ბილიკი | შიგთავსი |
|---|---|
| `index.html`, `ka/`, `en/` | გვერდები (ქართული ვერსია იგივეა root-ზეც და `/ka/`-შიც, როგორც ორიგინალზე) |
| `media/` | სტატიების და გალერეების სურათები |
| `_cdn/` | თემის CSS/JS/ფონტები/აიქონები (ორიგინალზე `cdn.gweb.ge`-დან იტვირთებოდა) |
| `templates/`, `includes/`, `buffer/` | თემის დამატებითი ასეტები |
| `.nojekyll` | GitHub Pages-ს ეუბნება, რომ Jekyll-ით არ დაამუშაოს (საჭიროა `_cdn/`-ის გამო) |

გვერდები დირექტორიის სახითაა (`ka/contact/index.html`), ამიტომ URL-ები ორიგინალის
იდენტურია: `/ka/contact/`, `/ka/produqtebi/pergola/` და ა.შ.
ყველა შიდა ბმული ფარდობითია, ამიტომ საიტი მუშაობს როგორც
`itconnectge.github.io/Alcom/`-ზე, ისე საკუთარ დომენზე.

## რით განსხვავდება ორიგინალისგან

* **საკონტაქტო ფორმა მოხსნილია** — PHP-ს საჭიროებდა და სტატიკურ ჰოსტინგზე ვერ იმუშავებდა.
  `/contact/`-ზე დარჩა მისამართი, ტელეფონები და ელ.ფოსტა.
* **სურათები შეკუმშულია** JPEG q82-ზე (703 MB → 178 MB). ზომა და კადრი უცვლელია.
* **ძებნა კლიენტის მხარეს გადავიდა** — CMS-ის სერვერული ძებნის ნაცვლად
  წინასწარ აგებული JSON ინდექსი + `assets/search/search.js`. იხ. „ძებნა“ ქვემოთ.
* **გვერდების დაყოფა** (`?start=12`) ახლა `@start=12` სახითაა, რადგან სტატიკური
  ჰოსტინგი query string-ს არ ამუშავებს.
* **რუკა შეცვლილია** — Google Maps-ის ნაცვლად OpenStreetMap (Leaflet, ლოკალურად `assets/leaflet/`).
  პინი დასმულია `41.7594404, 44.7591153`-ზე. ორიგინალზე რუკა საერთოდ არ იტვირთებოდა,
  რადგან CMS-ს Google-ის API key არ ჰქონდა ჩაწერილი.

## ძებნა

ძებნა მთლიანად ბრაუზერშია — სერვერი არ სჭირდება.

| ფაილი | დანიშნულება |
|---|---|
| `assets/search/index-ka.json`, `index-en.json` | გვერდების ინდექსი: URL, სათაური და ტექსტის პირველი 1400 სიმბოლო |
| `assets/search/search.js` | ძებნის ლოგიკა და შედეგების რენდერი |
| `search/`, `ka/search/`, `en/search/` | შედეგების გვერდები; კითხულობენ `?q=`-ს |

ძებნა **ქვესტრიქონით** მუშაობს და არა ზუსტი სიტყვით — ქართულის ბრუნებას რომ გაუძლოს:
„პერგოლ“ იპოვის „პერგოლას“, „პერგოლის“ და „პერგოლები“-საც. მოთხოვნის ყველა სიტყვა
უნდა შეგვხვდეს გვერდზე; სათაურში დამთხვევა უფრო მაღლა აყენებს შედეგს.

**შიგთავსის შეცვლის შემდეგ ინდექსი თავიდან უნდა აეწყოს:**

```bash
python tools/build_search_index.py
```

დამხმარე სკრიპტები `tools/`-შია: `build_search_index.py` (ინდექსი),
`build_search_pages.py` (შედეგების გვერდები), `add_header_search.py`
(header-ის ძებნის ველი ყველა გვერდზე).
